这是一个基于 Python 和 PySide6 开发的现代化 GUI 视频下载工具。它本质上是为强大的命令行工具 yt-dlp 套了一层“漂亮的外壳”，旨在通过图形界面简化 Bilibili、YouTube 等平台的视频下载流程。

关键功能特性
多线程加速：内置并行线程设置（concurrent_fragment_downloads），最高支持 32 线程同步下载，极大提升了下载速度。

智能格式管理：

分辨率控制：支持从 480P 到 4K (2160P) 的自由切换。

一键转码：支持保存为 MP4、MKV、WebM，甚至可以直接提取视频为 MP3 音频。

自动化后期处理：

自动调用同目录下的 FFmpeg 进行音视频合并。

支持内嵌字幕、写入封面图以及注入元数据，确保下载的文件信息完整。

网络兼容性：预留了代理服务器（Proxy）接口和 Cookie 导入功能，方便处理需要特殊网络环境或会员权限的视频下载。

3. 技术实现细节
架构设计：采用 QThread 异步任务机制（DownloadWorker），确保在下载大文件或进行 FFmpeg 合并时，GUI 界面依然流畅，不会出现“假死”现象。

鲁棒性处理：

内置了 ANSI 转义字符清洗函数（clean_ansi），解决了命令行工具日志在 GUI 文本框中显示乱码的问题。

环境自适应：程序会自动识别运行环境（脚本或打包后的 EXE），并自动定位同级目录下的 FFmpeg 路径。
